# How to Run  

1. Clone the project to your local repository.  

2. Navigate to the project directory and open two terminals:  
    - **Terminal 1**: Navigate to the backend directory.  
      ```bash
      cd backend
      ```  
    - **Terminal 2**: Navigate to the frontend directory.  
      ```bash
      cd frontend
      ```  

3. In both terminals, run the following command to install dependencies:  
    ```bash
    npm install
    ```  

4. Start the backend server:  
    In the **backend terminal**, type:  
    ```bash
    node server.js
    ```  

5. Start the frontend development server:  
    In the **frontend terminal**, type:  
    ```bash
    npm run dev
    ```  

6. Open the provided link in your browser to use the website.
